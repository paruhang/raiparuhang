How to resize and compress an image

Everything happens locally using the HTML5 Canvas API — nothing is ever uploaded.

  1. 1

    Choose an image, or several for batch mode

    Tap or click the upload area — the whole box is tappable on mobile — or drag and drop on desktop. Switch to Batch Mode first if you want to process many images with the same settings at once. Phone photos are automatically rotated to match their EXIF orientation, so portrait shots don't come out sideways.

  2. 2

    Crop, resize, and set a format (optional)

    Click the Crop button right below the preview to select just the region you want, then pick a resize mode — exact pixels, a percentage, fit within a max dimension, a physical print size at a given DPI, or a social media preset. Choose JPG, PNG, or WEBP, and either set a quality level or a target file size in KB/MB.

  3. 3

    Process, then download or copy

    Click Resize & Compress to see the exact size saved and final dimensions. Download the file, copy it straight to your clipboard to paste elsewhere, or in batch mode download every processed image as a single ZIP.

Are my images uploaded to a server?

Never. Everything runs in your browser using the HTML5 Canvas API. Your images never leave your device at any point — no upload, no server, no data stored anywhere.

What's the difference between resizing and compressing?

Resizing changes the pixel dimensions (e.g. 4000 × 3000 → 800 × 600). Compression reduces the encoded file size by lowering JPEG/WEBP quality without necessarily changing the dimensions. You can do both at once, or just one.

How does "Target File Size" work?

Enter a target (e.g. 200 KB) and the tool automatically binary-searches the best JPEG/WEBP quality level to hit that size as closely as possible. It doesn't apply to PNG, since PNG is lossless and has no quality dial to adjust — you'll see a note if you try to combine the two.

Why does my phone photo look correctly oriented, even though it was shot in portrait?

Phone cameras often save photos with the raw sensor orientation plus a rotation flag in the file's EXIF metadata, rather than physically rotating the pixels. This tool reads that flag and rotates the image before processing, so the output matches what you saw when you took the photo — instead of coming out sideways, which is a common problem with basic resizing tools that skip this step.

Can I process multiple images at once?

Yes — switch to Batch Mode, add as many images as you need, configure the settings once, then hit "Process All & Download ZIP." A file that fails to process (corrupted or unreadable) is skipped with a note, rather than stopping the whole batch.
