About this converter

Preeti is a glyph-substitution font: it maps Devanagari letter-shapes onto ordinary English keyboard keys, so text typed in Preeti is really just plain ASCII wearing a Nepali costume. That's fine as long as everyone viewing the text has the Preeti font installed — but it breaks on modern platforms (browsers, phones, government portals) that expect real Unicode Devanagari. Use "Preeti → Unicode" to fix old Preeti text for modern use, or "Unicode → Preeti" to go the other way if you need to match a legacy layout that still expects Preeti.

"Preview as Devanagari" loads the actual Preeti font and applies it to the Preeti box, so you can see the text the way it originally rendered before comparing it against the Unicode side.

How to convert Preeti to Unicode

Converting takes a few seconds — no account, no upload, and nothing installed. Here's the full walkthrough, plus notes for specific devices and situations.

  1. 1

    Paste or type your text

    Drop old Preeti-encoded text into the left box, or type directly if you still have a Preeti keyboard layout set up. If you're going the other way, type or paste Nepali Unicode into the right box instead.

  2. 2

    Pick a direction

    Use Preeti → Unicode to bring old text into the modern Unicode standard, or switch to Unicode → Preeti if you need to match a legacy system that still expects the old font encoding. The panels swap sides automatically so the box you're editing always stays on the left.

  3. 3

    Copy the result

    Click Copy on the output panel and the converted text is on your clipboard — ready to paste into Word, WhatsApp, Facebook, or a government portal. Nothing is saved or sent anywhere; it disappears the moment you leave the page.

How to preview Preeti text before converting

Click Preview as Devanagari above the Preeti box to render it in the actual Preeti font — the way it looked in its original source — so you can sanity-check it against the Unicode output before you commit to the conversion. If the button reports the font is missing, that's just a local setup note for this file's owner and doesn't affect conversion accuracy.

How to convert Preeti to Unicode on Mac, Windows, or mobile

This runs entirely as JavaScript in your browser, so there's nothing to install on any platform. Open this page in Safari or Chrome on Mac, Chrome or Edge on Windows, or Safari/Chrome on iPhone and Android — paste your text the same way on all of them. On mobile, use your keyboard's paste option or long-press inside the box.

Why won't my old Nepali text display correctly?

If text typed in Preeti shows up as random symbols or boxes, it's because Preeti isn't a real Unicode font — it reassigns Devanagari shapes to plain English keys, so it only looks right on a device that has the Preeti font installed. Converting it to Unicode with this tool makes it render correctly everywhere, permanently, without needing that font again.

Can I convert Unicode Nepali text back to Preeti?

Yes — switch to Unicode → Preeti using the toggle above the panels. This is useful if you need to match an older layout, publication, or piece of software that was built expecting Preeti-encoded text rather than Unicode.

Is my Nepali text uploaded anywhere?

No. The entire conversion runs client-side in JavaScript — nothing you type or paste is sent to a server, stored, or logged. That makes it safe to use for anything, including personal letters, legal documents, or confidential notes.
